# 2FA Freebies Kit

Part of the freebies kit series from Asdale Dynamics, LLC. Printable, privacy-first, no account needed.

## Contents

- `setup-worksheet.md` / `html/setup-worksheet.html` — enable 2FA on any account, step by step
- `recovery-code-log.md` / `html/recovery-code-log.html` — log recovery codes and where they are stored
- `authenticator-comparison.md` / `html/authenticator-comparison.html` — compare authenticator apps side by side
- `backup-plan.md` / `html/backup-plan.html` — plan for lost phones, broken devices, and account recovery

## Printing

Open any `.html` file in your browser and choose File → Print. Each page is styled for clean printing (`@media print`) and works offline.
